# Интерактивная платформа для истории

Интерактивная учебная платформа с карточками формата `выбор ответа` о жизни обычного человека в эпоху Советского союза. Сейчас проект работает как статическое SPA без сборщика, поэтому его можно сразу разместить на GitHub Pages.

## Что уже есть

- интерактивная карточка с вопросом, ответом и объяснением;
- 51 вопрос из согласованных списков в отдельном JSON-файле;
- поддержка вопросов с четырьмя вариантами ответа;
- фильтр по историческому периоду;
- перемешивание вопросов при каждом новом прохождении;
- режим прохождения в порядке файла без перемешивания;
- прогресс, счет, серия правильных ответов и лучший результат для выбранного периода;
- задел под разные типы вопросов через поле `type`;
- отдельная JSON-схема для будущего расширения базы вопросов;
- адаптивный интерфейс без внешних зависимостей.

## Быстрый запуск

```bash
python3 -m http.server 8000
```

После запуска открой:

```text
http://127.0.0.1:8000
```

## Проверка

```bash
node tests/run.mjs
```

## Где менять вопросы

Вопросы лежат в [`data/questions.json`](./data/questions.json). Для добавления новых вопросов сохраняй текущую структуру:

```json
{
  "id": "ussr-life-011",
  "type": "multiple_choice",
  "period": "СССР",
  "question": "Question text",
  "options": [
    { "id": "a", "label": "First option" },
    { "id": "b", "label": "Second option" },
    { "id": "c", "label": "Third option" },
    { "id": "d", "label": "Fourth option" }
  ],
  "answer": "b",
  "explanation": "Короткое объяснение после ответа.",
  "difficulty": "easy",
  "tags": ["быт", "город"]
}
```

## Архитектура

```text
.
├── index.html
├── styles.css
├── data/
│   ├── questions.json
│   └── questions.schema.json
└── src/
    ├── main.js
    ├── core/
    │   └── quizEngine.js
    ├── services/
    │   ├── questionRepository.js
    │   └── storage.js
    └── ui/
        └── quizView.js
```

`quizEngine` ничего не знает о DOM, `quizView` ничего не знает о загрузке данных, а вопросы лежат отдельно. Благодаря этому можно будет спокойно добавить новые режимы, коллекции, анимации, аудио, иллюстрации или полноценный дизайн-фреймворк.

## GitHub Pages

Так как проект статический, достаточно включить GitHub Pages для ветки `main` и корневой папки репозитория.
