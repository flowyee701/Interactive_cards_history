# Интерактивная платформа для истории

Интерактивная учебная платформа с карточками формата `правда / ложь` о жизни обычного человека в эпоху Советского союза. Сейчас проект работает как статическое SPA без сборщика, поэтому его можно сразу разместить на GitHub Pages.

## Что уже есть

- интерактивная карточка с вопросом, ответом и объяснением;
- 10 mock-вопросов в отдельном JSON-файле;
- фильтр по историческому периоду;
- прогресс, счет, серия правильных ответов и лучший результат;
- задел под разные типы вопросов через поле `type`;
- отдельная JSON-схема для будущего расширения базы вопросов;
- адаптивный интерфейс без внешних зависимостей.

## Быстрый запуск

```bash
python3 -m http.server 8000
```

После запуска открой:

```text
http://127.0.0.1:8000
```

## Где менять вопросы

Вопросы лежат в [data/questions.json](/Users/maksimbelavskij/Documents/New%20project%203/data/questions.json). Для добавления новых вопросов сохраняй текущую структуру:

```json
{
  "id": "ussr-life-011",
  "type": "true_false",
  "period": "1970-е",
  "question": "Текст утверждения",
  "answer": true,
  "explanation": "Короткое объяснение после ответа.",
  "difficulty": "easy",
  "tags": ["быт", "город"]
}
```

## Архитектура

```text
.
├── index.html
├── styles.css
├── data/
│   ├── questions.json
│   └── questions.schema.json
└── src/
    ├── main.js
    ├── core/
    │   └── quizEngine.js
    ├── services/
    │   ├── questionRepository.js
    │   └── storage.js
    └── ui/
        └── quizView.js
```

`quizEngine` ничего не знает о DOM, `quizView` ничего не знает о загрузке данных, а вопросы лежат отдельно. Благодаря этому можно будет спокойно добавить новые режимы, коллекции, анимации, аудио, иллюстрации или полноценный дизайн-фреймворк.

## GitHub Pages

Так как проект статический, достаточно включить GitHub Pages для ветки `main` и корневой папки репозитория.
